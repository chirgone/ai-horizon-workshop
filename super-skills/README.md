# Cloudflare OS Super Skills

Super Skills package repeatable workshop behavior without hiding evidence, uncertainty, or approval boundaries.

## Workflow

1. Evidence Register Builder
2. Severity Rationale Reviewer
3. Executive Summary Writer
4. Remediation Roadmap Planner
5. Report Quality Gate Auditor

## Operating contract

- Skills use customer-approved inputs only.
- Skills do not authorize MCP, retrieve data, execute writes, approve risk, close human gates, or distribute reports.
- Every output remains a draft until its named approval gate is closed by a person.
- Prompts are reusable instructions, not autonomous execution.
- Customer evidence remains inside its governed Workspace and session-scoped report flow.

Each Skill directory contains its canonical `SKILL.md` contract.
